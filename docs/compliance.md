# 合规与数据边界

CampusGuide 是个人学习/作品集演示项目，不是学校官方系统。

## 数据

- 目标院校：华南农业大学；只处理公开制度、办事指南、培养方案等公开材料；
- 早期快照截止：**2026-10-25**；后续补采及测评使用各自冻结快照，未声明实时全量覆盖；
- 早期演示库为225份文档 / 244版本 / 4,026个可检索块；本轮原生诊断库为10,047存储块、9,589可检索块。21个OCR块仅接入隔离实验，未完成全库OCR或生产切换；
- 来源与版本登记在 `configs/sources.yaml`，抓取/解析过程保留 URL、日期和哈希；
- 公开仓库与 Docker 镜像均不包含原始语料全文、完整解析文本、向量索引、模型权重或 `.env`；
- `data/` 中的生成物按本地环境恢复，仓库只提交必要的评测报告、标注/核对表和演示截图。

## 个人信息

- 系统不查询个人成绩、排名、学号、身份证、宿舍、一卡通或非公开联系方式；
- UI 固定提示“请勿输入学号 / 身份证 / 成绩单”；
- 隐私/校外请求在 guard 层拒答，不进入检索和答案渲染；
- trace、调试面板和报告使用脱敏字段，不展示 API key、`.env`、完整系统提示词、`text_raw_ref` 或用户隐私原文；
- 抓取/入库前对联系方式做正则脱敏；演示截图不包含真实姓名、学号或内部路径。

## 模型与密钥

- 模型通过 OpenAI-compatible API 调用；`LLM_API_KEY` 只从 `.env`/环境变量读取；
- `.env` 被 `.gitignore` 和 `.dockerignore` 排除，不进入镜像或 git；
- Docker Compose 通过 `env_file` 注入运行时配置；镜像构建上下文不包含 secrets；
- 本仓库不承诺第三方模型的可用性、数据驻留或 SLA；生产化需另做密钥管理、审计和限流。

## 回答边界

- 答案是“基于公开证据的可核对摘要”，不构成官方答复、政策解释或办理承诺；
- 证据不足、引用不支持、版本冲突、校外/隐私问题会明确拒答或标注 partial；
- 历史版本并排回答、跨学校、个人数据查询、公开多租户不在当前范围；
- README 区分当前 V7 诊断与历史 ultraspeed 记录，不把不同题集、不同语料的测评数值混为生产保证；

## 评测口径

- 2026-11-04已停止调参并保留V7；本轮50题原生库测评与8题局部OCR增补均不是独立上线验收，仍存在错答、误拒和覆盖误判；

- 历史 W6 总门禁通过；历史 W7 质量门禁通过但 p50/p95 未达原阈值，其当时状态为 **failed/tagged**，不替代当前V7结论；
- W8 页面 smoke 只验证 UI/链路，不替代 W6 20 题或 W7 冻结集；
- 所有报告保留原始 run、标签/核对表与限制，不选择性隐藏失败指标。
