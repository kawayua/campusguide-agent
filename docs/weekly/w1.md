## 风险与处理

| 风险 | 影响 | 当前处理 |
|---|---|---|
| PDF 版式复杂、扫描件无文本层 | 切分与引用不可靠 | 解析阶段记录告警；W1 不承诺 OCR；低质量文档走人工复核 |
| 真实文件缺少发布日期/生效日期 | 版本解析失败 | `build_index` 直接报错，要求补 `sources.yaml` |
| 联系方式脱敏误伤正文 | 条款语义变化 | 规则仅匹配明确模式；部门公开座机保留；原始快照不入库 |
| Windows 路径与 GBK 控制台 | CLI 输出乱码/路径错误 | 全部使用 `pathlib`；测试固定 `--basetemp`；文档给 Windows 用法 |
| 开发机未安装 `make` | `make` 命令不可用 | README 给出 `python -m uv run ...` 等价命令；`scripts/qa.sh` 可在 Git Bash 运行 |
| Qdrant 本地模式与服务器能力差异 | payload 索引/alias 行为不同 | 初始化失败只记 warning；W4 接真实 Qdrant 时补契约测试 |
| 语料版权与再分发 | 不能公开全文 | 仓库只提交清单、元数据、哈希与短引文；快照本地保存 |
