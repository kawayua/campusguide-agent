### 块类型分布

W1 的 3,952 条可检索块不是同质的“条款”：

| block_type | 数量 | 含义 |
|---|---:|---|
| `article` | 1,366 | “第 X 条”条款，条款级切分与评测的对象 |
| `section` | 2,586 | 培养方案节、教师详情段落、新闻/讲座目录等 |

因此 W1 的 20/20 只统计 `article`；`section` 只能作为结构抽查，不能计入“条款切分正确率”。

关键修复：

- 无分隔符条款号（如“第二十四条学生可以…”）按缺失序号用宽松规则补充，2009 年学籍细则不再缺条；
- PDF 中文硬换行续排，消除引文中的词内空格；
- 清除网页/WPS 导出的私用区列表字形；
- 联系人脱敏仅匹配“联系人/负责人/经办人：姓名”字段，避免把“负责人履行第一责任人”误脱敏；
- HTML 表格改为原位置块级占位，避免表格文本被提前到全文开头并挂到错误条款；
- 学院 CMS 列表页增加 `.paging_content`、`.col_news_list`、`#xzld` 主内容识别，避免把导航和友链入库；
- 近一年栏目按“日期｜标题｜链接”逐行独立成块，避免多条合并后无法精确引用；
- 2020 级数学扫描件完成 OCR 旁路，索引可用。

## W2 前必须明确的设计口径

### 1. 区分 `block_type`

“条款级 RAG”只适用于 `article`。W2 检索、证据包、引用卡片和评测必须携带 `block_type`：

- `article`：引用显示“第 X 条”，计入条款召回/引用指标；
- `section`：引用显示章节或段落，不计入条款指标；培养方案、教师页、新闻目录不能按“条款”统计；
- 评测报告至少拆成 `article_recall@8` 与 `section_recall@8`，答案引用卡片显式标注块类型。

### 2. 日期置信度

16 个版本的日期是低置信锚点：15 个只知道文号年份，`published_at` 取该年 12-31；1 个（`agri-profile`）取月份锚点 2025-06-30。当前版本解析把它们当精确日期使用。

W2 必须：

- 在版本/证据元数据中携带 `date_confidence`（至少 `high` / `low`）；
- 引用卡片对 `low` 显示“日期为文号年份/月份锚点，非精确发布日”；
- 处理“去年/2020 年版本/当时有效版本”这类问题时，先按低置信区间判断，并在答案中提示日期不确定，不能把 12-31 当成真实发布日；
- 历史版本比较时，优先比较版本序号和文号，不把锚点日期作为唯一排序依据。

### 3. Flow 引用门禁延后到 W5

W1 只登记 `flow_ids`，不实现流程事实的引用门禁。流程步骤、材料清单、条件判断的逐项引用校验延后到 W5 流程 DSL；W1/W2 的引用门禁只覆盖 `article`/`section` 问答。

## 已知限制

- 16 个版本只知文号年份或月份，`published_at` 为保守锚点，`notes` 标注 `date_confidence=low`；拿到准确日期后应回填。
- 2,586 条 `section` 包含培养方案、教师 CV、新闻目录等异质内容，不能当作条款统计。
- 农学院教师长 CV 会切成较多段（储成才 92 段、陈乐天 49 段），W2 检索需按文档去重。
- 4 个近一年栏目只存标题级目录，不覆盖讲座摘要、通知正文和附件。
- 当前 213 文档中，43 个为本地转录/汇总，无 HTTP 状态；引用链接仍指向官网。
- Qdrant 只有集合骨架，**没有 embedding，也没有写入向量点**；W2 才建向量。
- 当前没有任何问答效果指标，评测报告中的效果数字从 W7 开始产生。

## 风险与处理

| 风险 | 影响 | 当前处理 |
|---|---|---|
| PDF 版式复杂、扫描件无文本层 | 切分与引用不可靠 | 解析阶段记录告警；P2 已 OCR 两份 2020 数学扫描件；其余低质量文档走人工复核 |
| 真实文件缺少发布日期/生效日期 | 版本解析失败 | `build_index` 直接报错，要求补 `sources.yaml` |
| 低置信日期被当精确日期 | 历史版本答错 | W2 增加 `date_confidence` 与提示；历史比较不按锚点日期唯一排序 |
| `section` 被误当条款统计 | 评测指标虚高 | W2 在检索、引用、评测中显式区分 `block_type` |
| 联系方式脱敏误伤正文 | 条款语义变化 | 规则仅匹配明确模式；院系公开名录按配置保留；原始快照不入库 |
| Windows 路径与 GBK 控制台 | CLI 输出乱码/路径错误 | 全部使用 `pathlib`；测试固定 `--basetemp`；文档给 Windows 用法 |
| 开发机未安装 `make` | `make` 命令不可用 | README 给出 `python -m uv run ...` 等价命令；`scripts/qa.sh` 可在 Git Bash 运行 |
| Qdrant 本地模式与服务器能力差异 | payload 索引/alias 行为不同 | 初始化失败只记 warning；W4 接真实 Qdrant 时补契约测试 |
| 语料版权与再分发 | 不能公开全文 | 仓库只提交清单、元数据、哈希与短引文；快照本地保存 |
