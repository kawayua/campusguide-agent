## 1. UI

- 三栏工作台：历史在左、对话在中（输入固定底部）、办理清单/引用/调试在右；
- 冷白主题 + STSong 衬线标题；正文无衬线；
- 历史由 `gr.BrowserState` 持久化到同一浏览器 localStorage，刷新恢复会话、消息和最后一轮结果；
- 选中历史自动展开右栏；新对话收起；
- 移动端：左上角 `☰` 打开历史抽屉；结果卡片默认不占位，点“结果”或选择历史后从底部上滑约 40dvh；发送后自动收起；
- 历史抽屉/底部 sheet 的选中、关闭和发送行为均用真实浏览器回归。

## 2. 图与进度

- `GraphRunner.stream()` 与 `ConversationService.handle_stream()` 只输出节点进度，final 才携带 `ConversationReply`；
- 节点：planner → flow/retriever → advisor → verifier → finalize；
- 不流式输出未核对 claim/answer token；
- UI 后端 `GraphBackend` 启动时 warmup，MCP/检索预热后再接第一问；
- 单轮默认 120s fail-closed；同会话在途保护，超时后未收尾前不允许重复发送。

## 4. Docker 与 CI

- 多阶段 `Dockerfile`：CPU-only torch `2.14.1+cpu`，非 root，排除 CUDA 依赖；
- `compose.yaml`：Qdrant + app、`env_file`、data/HF volume、app healthcheck、
  `depends_on: service_healthy`；
- `scripts/demo_preflight.py`：`.env`、processed/manifest、points=4026、hash 一致；
- `make demo-up`：preflight + `docker compose up -d --build`；
- 镜像 `campusguide:local` 2.79GB；`docker compose config` 通过；fake/真实入口
  容器均 HTTP 200；真实 compose app 健康检查通过；
- CI 增补 `compileall`、YAML 配置加载、带 `.env.example` 的 `docker compose config`。
