# 三个内容缺口的修改方案（098 / 035 / 020）

第一批线上重跑暴露出三个"答案内容不完整但系统仍判已答"的缺口。本文给出定位、
改动点、判定规则、验收标准与风险控制；049 的时延问题作为附录取舍方案一并列出。

- 状态：A1–A5、B1–B2、B3、B4–B5 已实施，833 passed；线上复验见 §七
- 依据：`data/eval/answer_quality/live_batch1_20261029/batch1_judgement.md`
- 约束：不改历史 100 题答案与人工判定；新判定只写新文件/新字段

## 一、缺口定位

### 1.1 098：被拒的全量枚举没有换来正确改写

真实原文（无标点连续名录）里是 **3 个示范中心 + 12 个普通实验室**。答案把实验室
一起算成示范中心后被类别核对拒绝，但改写环节 **只丢了这条结论、没有补出
"三个示范中心"**，最终只答"设有云计算与大数据实验室"就被判 ANSWERED。

根因链：
1. `verification/conditions.py` 的 `category_violations` 只给出"哪一项不匹配"；
2. `advisor.revise()` 只收到 `issues`（自然语言），模型并不知道**必须列出哪几项**；
3. 改写失败后 `merge_revised_drafts` 保留原项/丢弃，没有"该方面仍未覆盖"的状态；
4. 覆盖核对把剩下的实验室结论当作覆盖了整句问题（fallback 方面），于是 ANSWERED。

### 1.2 035：具体缺口被"反向核对"吞掉

问题有两个并列方面："科研成果加分"与"学术不端如何规定"。答案只答了加分，
覆盖模型先判缺失，随后被 `CoverageChecker` 的反向核对改回 answered。

根因：`_claim_supports_unit` 对"整句问题当方面"（fallback）的单元一律返回 True，
只要有一条被引用的结论。035 的单元正是 fallback 方面，于是加分结论把
"学术不端"也一起覆盖了。

### 1.3 020：弱内容也算答出"毕业设计"

问题的毕业设计部分要的是 617017 行的 **6 学分 / 14 周 / 第 8 学期**。答案只写了
"毕业论文/设计是若干毕业要求的实现途径"，`_content_supports("毕业设计", …)`
因为 `_course_items` 找到 ≥1 个词就通过，反向核对随即判已答。

## 二、方案 A：拒绝后必须改写（098）

### A1 类型化实体清单（`verification/entities.py`）

新增两个纯函数，复用现有 `typed_entities`：

```python
def asked_types(question: str) -> list[str]:
    """问题里出现的类型词，按出现顺序去重（示范中心 / 重点实验室 / 研究中心…）。"""

def items_of_type(quote: str, type_word: str) -> list[str]:
    """原文中属于该类型的实体名，按原文顺序，全部为原文子串。"""
```

- 只认 `TYPE_WORDS` 里的类型词，不做同义扩展。
- 名称必须逐字出现在 quote 中；数量 > 8 时只返回前 8 个并附 `truncated=True`。

### A2 把"必须覆盖的项"带进改写（`agents/verifier.py` → `agents/graph.py`）

`VerificationReport` 增加字段：

```python
revise_requirements: list[dict]  # [{"kind": "category", "type_word": "示范中心",
                                 #   "required_items": [...], "forbidden_types": ["实验室"]}]
```

生成规则：当阻断性 finding 的 `kind == "category"` 时，用 A1 从**被引用原文**取
`required_items`，连同"禁止计入的类型"一起写入。graph 把它传给
`advisor.revise(..., requirements=...)`。

### A3 改写提示加"必须覆盖"块（`build_revise_messages`）

在现有 `失败原因` 之后插入：

```
必须覆盖（只能使用原文出现的名称，不得改写、不得合并）：
- 类型：示范中心
- 必须逐项列出：基于云平台的计算机实验教学示范中心；信息数学与应用统计实验教学示范中心；数学建模实验教学示范中心
- 不得把以下类型计入：实验室
未覆盖上述任一项时，不要输出该结论。
```

### A4 改写后复检 + 兜底（新增 `qa/list_claim.py`）

1. 复检：改写结果重新跑 `category_violations`；只要仍违规或"必须项未全部出现"，
   该 claim 不渲染，单元状态置 `verification_failed`，边界说明写明
   "所问类别的项目未能核实，仅列实验室"。
2. 兜底（仅限本情形）：用 A1 的结果拼一条**逐字引用型**结论：
   文本 = 对象 + "包括" + "、".join(required_items) + 引用；要求
   - 每个名称都是 quote 的子串；
   - 数量 ≤ 8；
   - 不新增任何数字/时间/评价词；
   - 仍走完整 validator + verifier（不给它开后门）。
   通过则渲染；不通过则按 1 处理。这样 098 不会停在"只答实验室"。

### A5 覆盖不得掩护未答方面

`coverage` 对"问题要求某类型清单、但没有任何 claim 列举该类型"的情况，
即使有其它 claim 命中 fallback 方面，也判 `generation_missing`，
`missing_items` 写具体类型（"示范中心清单"）。

## 三、方案 B：覆盖恢复不得吞掉具体缺口（035 / 020）

### B1 区分"主题回声"与"具体缺口"（`_clean_missing`）

```python
def split_missing(items, question) -> tuple[list[str], list[str]]:
    """返回 (主题回声, 具体缺口)。

    具体缺口 = 含数字/单位（学分、周、学期、元、%…）或含
    "具体/要求/材料/步骤/时间/名单/清单/规定"等实词，或清洗后长度 ≥ 8 且非问题子串。
    主题回声 = 问题原句、问题片段、"X + 方面名"这类没有信息量的占位。
    """
```

### B2 恢复条件收紧

`CoverageChecker` 的反向核对改为**同时满足**才恢复：

1. `concrete_gaps == []`（B1）
2. `deterministic_missing == []`
3. `_claim_supports_unit(unit, claim)` 为真

任一不满足 → 保持 `generation_missing` / `missing_evidence`，把具体缺口写进
`missing_items` 与最终"尚缺"段。

### B3 fallback 方面改成"并列子问题全覆盖"（035 的关键）

> 实施说明：第一次线上复验（live_gapfix_20261029）证明只靠 B1/B2 不够——补查把
> 缺失项改写成“未做明确规定”后，模型把单元判回 answered，035 又只剩加分。
> 因此 B3 最终启用：整句问题按并列成分切开，每个子问题的实词双字组需六成命中，
> “只命中学术（讲座）”不算答出“学术不端”；文档名、问法碎片（“纪律处分”）
> 与“替考/代考”这类同义说法各有白名单，避免误伤 001。

```python
def _question_parts(unit) -> list[str]:
    """把整句问题按 及/和/与/以及/，/、 切成并列子问题；切不动就返回整句。"""

def _covers_all_parts(parts, claim_text) -> bool:
    """每个子问题至少命中一个 ≥2 字的实词（去停用词、去方面名）。"""
```

在 `_claim_supports_unit` 中，fallback 方面（`aspect == original_span`）不再直接
`return True`，改为 `_covers_all_parts(...)`。035 的加分结论只覆盖"科研成果加分"，
"学术不端"这一支不命中 → 不恢复 → 答案必须补或明说缺。

### B4 `毕业设计` 的内容门槛提到"可核对要求"（020）

`_content_supports("毕业设计", text)` 改为必须命中其一：

- 带单位的数字：`\d+(\.\d+)?\s*(学分|周|学期|字|人)`
- 要求类实词：选题、开题、中期、答辩、查重、撰写规范、评阅、成绩构成

"作为实现途径课程设置"不再算答出。命中不足 → 不算已答，`missing_items`
写"毕业设计学分/周数/学期安排"。

### B5 最后一轮仍缺时，答案要"指名道姓"

`finalize` 的"尚缺"段改为优先渲染 `missing_items` 里的具体缺口（每条一行），
不再只写"尚缺 XX 方面"。同时 `boundary_notes` 区分"证据没有"与"答案没写"。

## 四、验收标准

### 4.1 离线（必须先绿）

新增测试文件 `tests/unit/test_content_gaps_098_035_020.py`，全部使用真实文本：

| 用例 | 断言 |
| --- | --- |
| 098 原文 + 只列实验室的结论 | 单元 `verification_failed`，最终 `PARTIAL_ANSWER`，答案含"三个示范中心"或明说未核实 |
| 098 原文 + 正确三中心结论 | 通过，且实验室不被计入 |
| 098 兜底逐字引用结论 | 通过 validator；名称逐字来自 quote；数量 > 8 时不生成 |
| 035 加分结论覆盖 fallback 单元 | 不恢复；`missing_items` 含"学术不端" |
| 035 加分 + 学术不端两条结论 | 恢复为 answered，claim_ids 为两条 |
| 020 "作为实现途径"结论 | 不算已答；`missing_items` 含"毕业设计学分/周数/学期" |
| 020 含 6 学分/14 周/第 8 学期结论 | 判已答 |
| 039 定义区别（回归） | 仍可恢复，不被 B1/B2 误伤 |
| 001 整句 fallback（回归） | 三条齐全时仍判已答 |

同时保持现有 818 项全绿；`test_r4_coverage_recovery.py` 中"整句 fallback 直接 True"
的用例要按 B3 改写（保留其"证据确已覆盖整句"的意图，换成三条子问题都命中的文本）。

### 4.2 线上（梯子第三级）

只重跑这三题，人工对照固定锚点：

- **098**：必须列出 3 个示范中心（名称逐字一致），并说明实验室另列；
- **035**：出现学术不端条款（第七节）或明确写"证据未收录学术不端条款"；
- **020**：出现 617017 的 6 学分 / 14 周 / 第 8 学期，或明确写缺这三项；
- 三题都不得在存在具体缺口时返回 ANSWERED。

达到以上才把三题从"离线回放通过"升到"线上验收通过"。

## 五、风险与回滚

| 风险 | 控制 |

出问题时单点关闭而不回滚代码。

## 附录：049 时延（非内容缺口）

两处收敛：

1. **改写预算**：改写前记录 `started_at`，超过 60 秒或连续两轮 finding 完全一致时
   停止改写，用已核实子集作答并标注缺口；
2. **降级路径**：改写失败但已有 ≥1 条通过结论时，直接 `PARTIAL_ANSWER`，
   不再为"补全"再跑一轮检索。

验收：049 在 120 秒内返回，且答案包含 163 / 必修 83.5 / 选修 37 / 实践 42.5 的
分层数值或明确缺口说明。
