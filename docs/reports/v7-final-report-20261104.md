# V7阶段总结与停止调参记录（2026-11-04）

本轮按用户要求结束调参，保留修改后的V7代码、原版B及既有V7快照和全部本地实验。当前版本可以继续研发和内部演示，但尚未通过正式上线验收。全库Xiaomi OCR重建未完成；此前50题运行在原生解析诊断库，随后仅将21个OCR影子块增补到隔离索引做8题对照。不能把这两项实验称为全库OCR版V7的验收。

## 已完成的实现与实际边界

既有开发按官方Qoder DeepSeek-Flash/max实现、Codex审查推进；OCR目标路线为本地Xiaomi为主、Gemini处理疑难区域。实现累积涉及解析结构、表格父子块/行列与来源证明、受众班型和文档关系、检索及原查询回退、引用ID修订、答案事实核验、覆盖判断和补答收敛。是否已经实现某个能力，与是否已在全库真实数据中可靠生效，应分别判断。

最后一轮答案/阈值修复限定7个源文件，新增4个测试文件、77项测试，未改既有18个配置和186个测试文件。修复覆盖程序/材料语义、同引用定向复核、列表意图约束、精确重复补答收敛和默认关闭的有限重排回退。完整离线测试2639通过、8个警告；33个独立构造反例通过，但既有22个覆盖反例仍有6个与基线相同的失败，不能宣称问题全部解决。阶段记录为本地`answer_threshold_repair_20261103`。

用户停止修bug后，50题及8题实验均固定接受代码。146个源代码/配置文件与接受快照保持一致；0.80只在测评进程中覆盖，仓库`configs/retrieval.yaml`仍为0.60，额外降阈值回退关闭。代码原有结构化精确匹配通路可以保留低于语义门槛的证据，并记录`STRUCTURED_THRESHOLD_BYPASS`；0.80不是答案正确概率，也不是全证据统一最低分。

公选课题OS003是直接引用OCR的改善案例：原生库已找到正确培养方案，但备注文字断行为“全校性公 选课选修 6 学分”“慕课2 学分”，答案数字被硬校验标为缺乏支持，最终未答；增补后最终引用OCR行，答出公选6学分、规定平台慕课可选2学分。不过末尾仍虚报缺少学分，因此只有内容通过，严格失败。该题耗时50.60→123.35秒，也不能说OCR提高了本次问答速度。

另一改善题CR078补出辅修学士与主修不同本科专业大类的条件，但用户引用仍是原生条款，不能把这一变化单独归因OCR。CR039仍漏微专业报名条件，CR088仍整题误拒，已答日期与课程继续被错误列为缺项。

文档级Recall/MRR不变而局部答案改善并不矛盾：两组都能找到同一文档，差别在具体行是否能提供可用文字。8题样本、单次输出、增补重复块与BM25全库重算，都限制了结论外推；不是全库OCR替换或独立解析效果消融。问答token并未因增补OCR下降，不能把本地识别节省云端OCR费用等同于回答阶段降本。

## 残留问题和发布判断

| 阶段 | 已观察问题 | 对用户的影响 |
|---|---|---|
| 解析与表格事实 | 工业工程与管理“工程伦理”仍错归公共必修；超宽表及部分来源定位待复核 | 字都存在仍可能归错课程类别 |
| 检索与阈值 | 教学楼、困难补助、毕业学位等可答题仍被低分过滤 | 整题误拒；0.80并未独立校准 |
| 来源与适用范围 | 推免申诉借用助学金公示渠道；数学招生分类替代指定培养方案方向 | 引用存在但业务或版本口径不对 |
| 内容完整性 | 替考处分、转学材料、微专业报名条件仍会漏答 | ANSWERED不能保证真正答全 |
| 覆盖与补答 | 已答日期、学分、课程被虚报缺项，近义补答仍重复 | 不必要多轮、答案混乱和高p95 |
| 生成事实 | 主持行政工作的副院长被先称院长 | 不能据相关工作分工推定正式职务 |

当前结论是停止继续打补丁、保留可回溯研发版本，未发布生产、未切正式别名。下一阶段若恢复工作，应先完成全库OCR批处理与文档桥接、页/区域覆盖和表格来源核验，建立独立dense+sparse索引并在测评前校验索引身份，再以固定代码复测。新阈值只在未参与修复的独立dev上校准，holdout一次性验收；本报告不预先承诺收益或把开发样本当验收。

## 评分、证据与复现

内容通过要求问题必要信息在完整可见回答（含引文）中出现且无实质错误；正确澄清/合理限答也可通过。严格交付另要求完成正文归纳，没有虚报缺项、伪冲突或核验未完成。错误标记可重叠，不能相加当失败题数。没有独立原子事实标签，因此不报告伪精确必答项覆盖百分比。

Recall按实际前K个证据块截断后匹配文档＋版本、同来源去重；首次与最终分别记录，空检索计0，全题纳入分母。50题共71个相关文档版本关联。MRR取前K中首次相关来源倒数排名的均值。p95采用线性分位数，含题内等待与重试、排除模型预热和用户暂停，不是并发服务SLA。
