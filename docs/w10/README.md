# W10 求职材料与收尾

| 文件 | 用途 |
|---|---|
| `30s-intro.md` | 30–40 秒中文/英文项目介绍 |
| `resume-bullets.md` | RAG / Agent 两个岗位版本的简历 bullet |
| `interview-qa.md` | 12 个高频问题 + 追问速答 |
| `metrics-ledger.md` | 所有数字的口径、来源、禁止表述 |
| `mock-interview.md` | 30–40 分钟模拟面试脚本与评分表 |

## 原则

- 数字只从 `metrics-ledger.md` 取；
- W7 是 failed/tagged，W9 是 deferred，不写成通过/merged；
- 评测 ultraspeed 与生产 vPro 分开；
- 主动说失败，比只报喜更可信。

## 建议练习顺序

1. 30 秒录音 3 遍，控制在 40 秒内；
2. 按 `mock-interview.md` 自问自答；
3. 每个数字回到对应报告核对一次；
4. 最后只保留 3 个最强数字：**4,026 块、39/39 引用 + 0 quote mismatch、92.7% 人工 support**。
